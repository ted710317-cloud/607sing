# 🎵 班級雲端 YouTube 點歌系統 (Classroom Jukebox)

專為中小學教室課堂、下課時間、午休掃除、同樂會設計的即時 YouTube 點歌廣播系統。  
學生拿起手機/平板掃碼免登入即可點歌並附帶「點播寄語」，老師的大螢幕/投影機自動同步輪播，並具備強大的「防惡搞守門員」機制與「行動遙控後台」！

## 🌟 五大核心設計特色

### 1. 🖥️ 播放端 vs. 📱 點歌端 雙向即時分離
- **大螢幕播放端 (`player.html`)**：專為班級投影機設計，暗色系高質感介面、動態等化器音波、待播排隊清單，右上角常駐點歌動態 **QR Code**。
- **學生點歌端 (`request.html`)**：免下載、免註冊登入。手機掃描即可輸入座號、貼上 YouTube 網址，並支援「即時預覽縮圖與標題」。
- **全球雲端即時同步**：基於全球 MQTT over WSS 雲端節點，學生一送出點播，大螢幕 1 秒內即時更新排隊清單！

### 2. 🛡️ 嚴格的「教室守門員」機制（防惡搞與洗版）
- **時長上限自動過濾**：自動檢測 YouTube 影片長度，超過上限（預設 6 分鐘，可自由自訂）直接退件，阻擋 10 小時循環洗腦影片。
- **個人配額上限**：限制每位學生同時最多只能排隊 2 首歌，播畢後才能再點，防止少數同學霸佔歌單。
- **重複歌曲防護**：自動過濾已在佇列中或正在播放的歌曲。

### 3. 💌 學生互動與點播寄語（班級經營神兵利器）
- **大螢幕專屬點播卡**：播放該首歌曲時，大螢幕正中央會醒目展示：  
  > *「來自 座號 15 號 小明 的點播寄語：祝全班段考拿第一名！衝刺加油！」*
- **民主投票排序（Upvote）**：學生可在手機上看即時清單，並為喜歡的歌點「👍 按讚」，系統可切換「按讚最高者優先插播」模式！

### 4. 🎛️ 老師專屬快捷控制與行動遙控後台 (`admin.html`)
- **實體快捷鍵（大螢幕）**：
  - `空白鍵 (Space)`：暫停 / 繼續播放
  - `N` 或 `→`：一鍵跳過切下一首（遇到突發狀況秒切）
  - `M`：靜音開關
  - `F`：全螢幕切換
- **手機遠端巡堂遙控**：老師拿著自己的手機進入 `admin.html`（密碼預設 `admin888`），即可在教室後方遠端切歌、微調音量、一鍵清空或開啟「點歌先審核後播放模式」。

### 5. ⚡ YouTube IFrame API 深度優化與相容性處理
- **版權受限自動跳過（Error 101 / 150）**：遇上有版權保護、禁止外部嵌入的官方 MV 時，大螢幕會自動彈出提示並在 3 秒內自動無縫跳至下一首，絕不卡死！
- **Autoplay 規範相容**：首頁提供友善的「進入點播大螢幕」一鍵解鎖，滿足現代瀏覽器安全性限制，確保全自動順暢接歌。

## 💻 本機離線執行方式（選用）

如果您希望在完全沒有外網連線的區域網路執行，亦可使用本地 Node.js 伺服器：

1. 雙擊資料夾內的 **`啟動點歌系統.bat`**。
2. 或在終端機輸入：
   ```bash
   npm install
   npm start
   ```
3. 電腦開啟 `http://localhost:3000/player.html`。
