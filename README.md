# 🎵 班級雲端 YouTube 點歌系統 (Classroom Jukebox)

專為中小學教室課堂、下課時間、午休掃除、同樂會設計的即時 YouTube 點歌廣播系統。  
學生拿起手機掃碼免登入即可點歌並附帶「點播寄語」，老師的大螢幕/投影機自動同步輪播，並具備強大的「防惡搞守門員」機制與「行動遙控後台」！

---

## 🌟 五大核心設計特色

### 1. 🖥️ 播放端 vs. 📱 點歌端 雙向即時分離
- **大螢幕播放端 (`/player.html`)**：專為班級投影機設計，暗色系高質感介面、動態等化器音波、待播排隊清單，右上角常駐點歌動態 **QR Code**。
- **學生點歌端 (`/request.html`)**：免下載、免註冊登入。手機掃描即可輸入座號、貼上 YouTube 網址，並支援「即時預覽縮圖與標題」。
- **即時同步**：基於 Socket.IO WebSocket 技術，學生一點歌，大螢幕 1 秒內即時更新排隊清單。

### 2. 🛡️ 嚴格的「教室守門員」機制（防惡搞與洗版）
- **時長上限自動過濾**：自動解析 YouTube 影片秒數，超過上限（預設 6 分鐘，可自由自訂）直接退件，阻擋 10 小時循環洗腦影片。
- **個人配額上限**：限制每位學生同時最多只能排隊 2 首歌，播畢後才能再點，防止少數同學霸佔歌單。
- **重複歌曲防護**：自動過濾已在佇列中或正在播放的歌曲。

### 3. 💌 學生互動與點播寄語（班級經營神兵利器）
- **大螢幕專屬點播卡**：播放該首歌曲時，大螢幕正中央會醒目展示：  
  > *「來自 座號 15 號 小明 的點播寄語：祝全班段考拿第一名！衝刺加油！」*
- **民主投票排序（Upvote）**：學生可在手機上看即時清單，並為喜歡的歌點「👍 按讚」，系統可切換「按讚最高者優先插播」模式！

### 4. 🎛️ 老師專屬快捷控制與行動遙控後台 (`/admin.html`)
- **實體快捷鍵（大螢幕）**：
  - `空白鍵 (Space)`：暫停 / 繼續播放
  - `N` 或 `→`：一鍵跳過切下一首（遇到突發狀況秒切）
  - `M`：靜音開關
  - `F`：全螢幕切換
- **手機遠端巡堂遙控**：老師拿著自己的手機進入 `/admin.html`（密碼預設 `admin888`），即可在教室後方遠端切歌、微調音量、一鍵清空或開啟「點歌先審核後播放模式」。

### 5. ⚡ YouTube IFrame API 深度優化與相容性處理
- **版權受限自動跳過（Error 101 / 150）**：遇上有版權保護、禁止外部嵌入的官方 MV 時，大螢幕會自動彈出提示並在 3 秒內自動無縫跳至下一首，絕不卡死！
- **Autoplay 規範相容**：首頁提供友善的「啟動點播」一鍵解鎖，滿足現代瀏覽器安全性限制，確保全自動順暢接歌。

## 🚀 快速啟動指南（Windows 電腦）

### 方式一：一鍵雙擊啟動（最簡單）
直接在資料夾中雙擊執行：  
👉 **`啟動點歌系統.bat`**  
系統會自動檢查環境、啟動伺服器並自動為您開啟瀏覽器大螢幕！

### 方式二：指令列啟動
```bash
# 進入資料夾
cd youtube-jukebox

# 安裝依賴 (首次執行)
npm install

# 啟動伺服器
npm start
```

## 🌐 教室使用流程（連線教學）

1. **投影機/老師電腦**：
   - 開啟：`http://localhost:3000/player.html`（或啟動 bat 後自動開啟）。
   - 點擊畫面中央的「進入點播大螢幕」，解鎖音訊權限。
2. **學生手機/平板**：
   - 連線至**學校教室同一 Wi-Fi**。
   - 使用手機相機直接掃描大螢幕右上角的 **QR Code**（或輸入大螢幕上顯示的網址，如 `http://192.168.1.xxx:3000/request.html`）。
   - 貼上 YouTube 網址，即可送出點播！
3. **老師行動遙控**：
   - 手機瀏覽器開啟：`http://192.168.1.xxx:3000/admin.html`
   - 輸入預設密碼：`admin888`，即可巡堂遙控！

## ☁️ 雲端公開部署（跨網路 / 學生用 4G 行動網路亦可點歌）

如果您希望即使學生沒有連上學校 Wi-Fi（例如使用自己的 4G/5G 網路），也能順利點歌，可免費部署至雲端平台：

### 部署到 Render / Railway（推薦，5 分鐘搞定）
1. 將本專案上傳至您的 **GitHub 儲存庫**。
2. 註冊登入 [Render.com](https://render.com)（免費方案）。
3. 點選 **New Web Service**，連結您的 GitHub 儲存庫。
4. 設定值：
   - **Environment**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
5. 部署完成後，您會獲得一個專屬公開網址（例如 `https://class-jukebox.onrender.com`）。
6. 大螢幕播放端上的 QR Code 就會自動切換為該公開網址，任何網路皆可暢快點播！

## 📁 檔案結構說明

```text
youtube-jukebox/
├── package.json           # 專案依賴設定 (Express, Socket.IO, QRCode, Cors)
├── server.js              # 核心後端：即時通訊、YouTube解析、守門員規則與狀態儲存
├── data.json              # 待播清單與設定持久化快取（自動產生）
├── 啟動點歌系統.bat        # Windows 一鍵啟動指令稿
├── README.md              # 系統完整操作說明文件
└── public/                # 前端靜態網頁
    ├── index.html         # 入口首頁與身分選擇導覽
    ├── player.html        # 教室投影機專用大螢幕播放端
    ├── request.html       # 學生手機掃碼點歌端
    └── admin.html         # 老師專用行動遙控後台
```
